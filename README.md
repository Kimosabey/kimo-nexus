# Kimo Nexus | Stealth Portfolio

A high-performance, high-contrast, professional "Stealth" portfolio designed for a Senior Full Stack Hybrid Engineer.

**Theme**: Onyx Black, Silver Chrome, and Ghost White. Elite taste only.

## 🎨 Design System

- **Background**: Onyx Black (`#000000`) with Graphite (`#0A0A0A`) transitions.
- **Surface**: Charcoal Glass (`#121212` @ 40%) with backdrop blur.
- **Accents**: Silver Chrome (`#E5E5E5`) for strict 1px borders.
- **Typography**: Space Grotesk (Google Fonts).
- **Texture**: 3% Noise Grain + Subtle Mesh Gradients.

## ⚡ Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Motion**: [Framer Motion](https://www.framer.com/motion/) + [Lenis](https://lenis.studiofreight.com/) (Smooth Scroll)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Run Development Server**:
    ```bash
    npm run dev
    ```

3.  **Build for Production**:
    ```bash
    npm run build
    ```

## 🏗️ Architecture

- `src/app`: App Router pages and layouts.
- `src/components`: Reusable UI components (Magnetic Buttons, Glass Cards).
- `src/lib`: Utilities (Tailwind merge, etc.).
